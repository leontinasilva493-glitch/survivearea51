# Fast MVP Inner Pages Design

## Goal

Improve the guide in three ordered batches: current update accuracy and Map Lite, an indexable beginner guide, then a transparent coin benchmark. Preserve the evidence-first publishing policy throughout.

## Batch 1: update freshness and Map Lite

- Derive update copy from the current Roblox title instead of hard-coding `CRUELTY SOON`.
- Preserve title variants as signals for one Universe, never as separate games.
- Turn Map Lite into a clearer route sequence with an explicit evidence ledger and release gate.
- Keep `/map/` `noindex, follow` because the available evidence has four observed landmarks and one provisional Backrooms lead, below the documented map threshold.

## Batch 2: beginner guide

- Add `/beginner-guide/` as a task-oriented synthesis of already verified evidence.
- Cover the first run from spawn to the Normal Gun Shop, MP7 purchase context, facility entry, coin observations, and honest stop points.
- Make the page indexable because its value is the ordered first-run workflow, not duplicated weapon or map tables.
- Add it to navigation, homepage discovery, related links, structured metadata, and sitemap.

## Batch 3: coin benchmark

- Replace hand-entered derived values with a tested calculation helper using visible balances and elapsed seconds.
- Publish sample count, observed rate range, and named confounders as Benchmark v0.
- Add a reusable controlled-run capture protocol.
- Keep `/coins-rebirth/` `noindex, follow`: two event-window observations cannot become a normal-player baseline.

## Verification

- Each behavior change begins with a failing Node test.
- Run targeted tests after each batch.
- Finish with all tests, ESLint, TypeScript, and `next build`.

## Non-goals

- No invented Backrooms entrance, floor plan, rebirth requirement, coin source, Gamepass ROI, or fastest-route claim.
- No deployment, GSC submission, GitHub push, or changes to the untracked `survivearea51/` directory.
